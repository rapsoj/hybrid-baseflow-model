## Model structure

| Aspect | Current configuration |
|---|---|
| Forecast origin | One sample per day at 12:00 UTC |
| Encoder input | Last 14 days at 15 min = 1344 steps x 4 channels (rain_log1p, groundwater, rain_missing, groundwater_missing), patched by 24 steps into 56 tokens (tensor `(1344, 4)` per sample) |
| Decoder input | 112 tokens of 6 h covering the next 28 days; channels: gefs_mean_log1p, gefs_std_log1p, geosmart_member, season_sin, season_cos, anchor_log_flow (variant dependent; tensor `(112, 3-5)`); `geosmart_member` is one GeoSmart member's level trajectory (GEFS stays mean/std) |
| Target mode | `delta_log_last`: the network predicts log1p(flow) - log1p(anchor), anchor = mean observed flow over the last 24 h before the origin (also a decoder input channel `anchor_log_flow`); predictions are inverted to m³/s and every metric is computed in m³/s |
| Predicted quantity | `total_flow`: the observed HDE flow |
| Prediction output | the predicted quantity at the catchment gauge, next 28 days at 360 min (mean of the 15-min flow per bin) = 112 steps x 7 quantiles (0.05, 0.1, 0.25, 0.5, 0.75, 0.9, 0.95); tensor `(112, 7)` |
| Architecture | Encoder-decoder transformer: d_model 32, 4 heads, 1 encoder / 1 decoder layers, feed-forward 64, dropout 0.3; learned positional embeddings; non-causal decoder self-attention plus cross-attention; 112 output tokens each emitting 1 steps; non-crossing quantiles (lowest quantile + cumulative softplus increments) |
| Feature scaling | Standardisation fitted on the training split only (encoder channels, GEFS and GeoSmart channels separately, NaN -> 0 after scaling); mask and season channels unscaled; one scale shared by all GeoSmart members; target = log1p(flow) minus the target-mode offset, standardised (see Target mode) |
| Feature selection | None automatic. Fixed channel groups chosen per ablation variant: `with_geosmart` (GEFS on, GeoSmart on); `without_geosmart` (GEFS on, GeoSmart off); `geosmart_anomaly` (GEFS on, GeoSmart on); `geosmart_skip` (GEFS on, GeoSmart on); `geosmart_mean` (GEFS on, GeoSmart on); `geosmart_anomaly_mean_skip` (GEFS on, GeoSmart on); past flow is not an encoder input (only the 24 h mean flow anchor is given to the decoder, because target mode is delta_log_last); common samples only: True |
| Training | Pinball loss in scaled log1p space; AdamW lr 0.001, weight decay 0.01, batch 16, grad clip 1.0, up to 100 epochs, early stopping patience 15 on validation loss, seed 42; purged chronological split 70% / 15% / 15% with a 42-day purge gap (history + horizon). GeoSmart ensemble: every time a sample is used, one of its members is drawn at random as the groundwater channel (augmentation); validation loss uses 5 fixed random members per sample |
| Evaluation | All metrics are reported overall and per forecast week (week 1, week 2, ...): quantile loss in m³/s, median MAE, 0.05-0.95 interval coverage, baseline skill and extreme-event scores, on validation and test; both variants on identical samples; with GeoSmart the model is run once per member and the member predictive distributions are pooled as an equal-weight mixture (`pipeline/ensemble.py`); compared with climatology (training-flow quantiles), seasonal climatology (training-flow quantiles within +/-15 days of the target day of year) and persistence (flow at the origin held constant) via `skill_vs_*` = 1 - model/baseline quantile loss |
| Calibration | No post-hoc calibration. Calibration is only assessed through the empirical coverage of the 0.05-0.95 interval (nominal 0.90) and per-quantile loss |
| Extreme event skill | Event = flow above the 95% quantile of historic flow up to the end of train; flagged when the predicted q0.5 exceeds it; FNR, FPR, precision, recall, accuracy, F1, event rate per step and per forecast window. Extra regime report: observed daily flow is split into baseflow and runoff with a Boughton filter (k 0.95, C 0.5); target steps whose day has baseflow index >= 0.9 are baseflow-dominated, the rest runoff-dominated; quantile loss, median MAE, coverage and skill vs both baselines are reported for each regime, overall and per forecast week (reporting only, never a model input) |

## Joint chalk-catchment model

`python main.py all-chalk` trains one shared model on every eligible catchment (see `DATA.md`: all three HDE series, GEFS, GeoSmart members, enough aligned samples in every split, and a gauge that is not dry). Architecture, data, training and evaluation settings are those above, with these differences:

| Aspect | Joint model |
|---|---|
| Catchment embedding | `nn.Embedding(n_catchments, 32)` added to the encoder and decoder positional embeddings |
| Scaling | Encoder, GEFS, GeoSmart and target scalers are fitted per catchment on that catchment's training split only |
| Samples | Only origins where both GEFS and GeoSmart exist, for every variant; purged chronological split per catchment; the shared model trains on the pooled training splits |
| Variants | `with_geosmart` (mode level, ensemble members); `without_geosmart` (no GeoSmart); `geosmart_anomaly` (mode anomaly, ensemble members); `geosmart_skip` (mode level, ensemble members, skip connection); `geosmart_mean` (mode level, ensemble mean); `geosmart_anomaly_mean_skip` (mode anomaly, ensemble mean, skip connection) |
| GeoSmart options | `level` = absolute member level; `anomaly` = level minus the member's own level at the forecast origin; `members` = one member per pass; `mean` = ensemble mean as a single input; skip = zero-initialised linear map from the GeoSmart channel at each output token to that token's quantile outputs |
| Metrics | Per catchment on validation and test: all single-catchment metrics, plus per-regime and per-week breakdowns |
| Final run | `python main.py all-chalk-final`: seeds [42, 43, 44, 45, 46], `with_geosmart` compared with `without_geosmart`; results are written per seed and aggregated (mean and min-max over seeds) |
